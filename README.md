Each project lives in its own folder with a detailed README.

## Projects

| Project | Description | Tech |
|---|---|---|
| [Port Scanner](port-scanner/) | TCP connect and SYN scanner with multithreading and banner grabbing | Python, socket, Scapy |

Developed and tested on Kali Linux. All scans were performed only against
my own machines and `scanme.nmap.org`, which is provided for testing.
